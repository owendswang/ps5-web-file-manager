# PS5 Файловый менеджер

Менеджер файлов для PS5 с веб-интерфейсом. В первую очередь предназначен для быстрого и
безопасного копирования папок с дампами игр с USB-накопителя во внутреннюю память.

## Краткое описание

Полезная нагрузка (ELF) — веб-менеджер файлов для PS5. Он запускает HTTP-интерфейс, начиная с порта 8888, регистрирует лаунчер на главном экране в категории Медиа при запуске и предоставляет файловые операции из браузера PS5 или другого браузера в той же сети. Если 8888 уже занят, то пробует следующий порт, пока не найдёт свободный; уведомление при запуске и лаунчер на главном экране используют фактический порт прослушивания.

## Возможности

- Запуск из ярлыка в меню, реализовано через AppCache, предварительно надо ELF положить в /data/wfm/web-file-mgr-ru.elf.
- Просмотр списка файлов и папок.
- Сортировка списка по имени, типу, размеру, времени изменения или правам доступа. Выбранный режим сортировки сохраняется в локальном хранилище браузера.
- Изменение прав чтения/записи/выполнения из столбца прав с помощью флажков или октопольного числа.
- Копирование, перемещение, удаление, переименование, создание файлов и создание папок.
- Редактирование текстовых файлов UTF-8 размером до 1 МБ с помощью встроенного простого текстового редактора.
- Операции с множественным выбором.
- Копирование/перемещение путём выбора источников сначала, а затем вставки или перемещения их в текущую папку.
- Запросы при конфликтах для перезаписи файлов и объединения папок.
- Распаковка архивных файлов с расширениями .7z, .001, .zip, .zipx, .rar, .part01.rar, .arj, .bz2, .bzip2, .tbz, .tbz2, .cab, .gz, .gzip, .tgz, .tpz, .lzh, .lha, .tar, .xz, .txz, .z, .taz, .zst, .tzst, .xar, .xip, .cpio, .lzma, .pmd. Для распаковки требуется отдельно распространяемый помощник [wfm-7zip-helper.elf](https://github.com/owendswang/wfm-7zip-helper) по пути /data/wfm/wfm-7zip-helper.elf
- Загрузка одиночных файлов, нескольких файлов или папок из удалённого браузера с помощью средства выбора файлов или полноэкранного перетаскивания. Загрузка скрыта в браузере PS5, так как предназначена для другого устройства в сети.
- Скачивание выбранных элементов по отдельности: файлы скачиваются напрямую, а каждая папка скачивается как собственный tar-архив. Скачивание скрыто в браузере PS5.
- Полноэкранное наложение задач с отложенным отображением, прогрессом, скоростью, оставшимся временем, поддержкой отмены и восстановлением задачи после повторного открытия браузера, пока процесс всё ещё работает.
- Скопированным/перемещённым файлам и папкам устанавливаются права 0777, если файловая система поддерживает Unix-права. Файловые системы типа FAT/exFAT могут игнорировать chmod.
- Загруженные файлы записываются через временные файлы и переименовываются на место после завершения загрузки.
- Русский, китайский и английский интерфейсы. Язык браузера определяется из navigator.languages / navigator.language; китайский использует zh, русский - ru, всё остальное использует английский.
- Адаптивная вёрстка для узких мобильных браузеров, включая перенос панелей инструментов и горизонтально прокручиваемые списки файлов.
- Уведомление при запуске с названием приложения, версией и портом прослушивания.
- Иконка лаунчера на главном экране и favicon браузера используют одни и те же встроенные данные icon0.png в сборке для PS5, чтобы не хранить иконку дважды в ELF.
- Создание/редактирование текстовых файлов с расширениями .txt, .json, .xml, .ini, .cfg, .conf, .md, .log, .lua, .js, .css, .html, .htm, .c, .h, .cpp, .hpp, .sh, .csv, .yaml, .yml, .shn.
- Предпросмотр файлов изображений с расширениями .png, .jpg, .jpeg, .gif, .bmp, .webp.
- Установка/предпросмотр PKG-файлов с расширением .pkg.
- Запуск ELF-файлов путём отправки их в загрузчик по адресу localhost:9021 после подтверждения.
- Переключение браузера PS5 между полноэкранным и обычным режимом кнопкой в правом верхнем углу. После переключения браузер заново открывает текущую папку.

## Сборка

Сначала требуется PS5 payload SDK: [ps5-payload-dev/sdk](https://github.com/ps5-payload-dev/sdk#quick-start)


```sh
export PS5_PAYLOAD_SDK=/opt/ps5-payload-sdk
```

Инициализируйте закреплённые зависимости командой `git submodule update --init --recursive`.

В этом проекте используется libmicrohttpd для HTTP и libsmb2 для SMB. make проверяет наличие libmicrohttpd перед сборкой и автоматически запускает скрипт установки, если она отсутствует:

```sh
make
```

Если у сборочного хоста нет доступа к сети, скачайте исходный архив libmicrohttpd самостоятельно и один раз запустите установщик зависимостей:

```sh
LIBMICROHTTPD_TARBALL=/path/to/libmicrohttpd-1.0.1.tar.gz \
  ./install-libmicrohttpd.sh
```

Затем снова соберите:

```sh
make
```

Результат:

```text
web-file-mgr-ru.elf
```

Для локального тестирования браузера/интерфейса на Linux:

```sh
make linux
./web-file-mgr-ru-linux
```

Сборка для Linux не включает установщик лаунчера на главном экране PS5.

## Использование

Запустите загрузчик ELF на PS5. Обычный порт прослушивания — 9021.

Отправьте собранный ELF с помощью netcat или NetCat GUI:

```sh
export PS5_HOST=ps5_ip_address
nc -q0 "$PS5_HOST" 9021 < web-file-mgr-ru.elf
```

После запуска ELF уведомление PS5 показывает название приложения, версию и фактический порт прослушивания. Откройте показанный URL в браузере PS5, например:

```text
http://${PS5_IP_ADDRESS}:8888/
```

При запуске ELF регистрирует веб-ярлык PS5 Файловый менеджер в категории Медиа. Отсутствующие файлы лаунчера записываются; существующие иконки и названия сохраняются. Обновляется только URL в param.json для обновления фактического порта прослушивания, включая резервные порты, такие как 8889.

## Примечания

- Копирование, перемещение, удаление, загрузка и скачивание выполняются как одиночные фоновые задачи. Пока одна задача выполняется, другие файловые операции отклоняются.
- Удаление рекурсивное и безвозвратное. Корзины нет.
- Задачи копирования/перемещения можно отменять. Частично скопированный одиночный файл удаляется, но частично скопированные папки остаются на месте, чтобы не удалять существующие файлы при объединении с существующей целевой папкой.
- Задачи загрузки можно отменять. Частично загруженный временный файл удаляется, когда это возможно.
- Выбранные файлы скачиваются по отдельности, и каждая выбранная папка создаёт собственный tar-поток. Tar-архивы генерируются эльфом и не записываются сначала в хранилище PS5.
- Интерфейс может восстановить отображение активной задачи, если браузер был закрыт и снова открыт, пока процесс эльфоа всё ещё работает.
- Редактирование текста ограничено распространёнными расширениями текстовых файлов. Файлы не в UTF-8 и слишком большие файлы отклоняются.
- Имена файлов передаются как UTF-8 через веб-API. ELF также пытается сохранить устаревшие байтово-ориентированные имена, возвращаемые смонтированными файловыми системами, чтобы смешанные кодировки имён файлов на USB всё ещё могли отображаться и обрабатываться.

## ЧаВо
- Необязательная кнопка полноэкранного режима изменяет раскладку браузера в ОЗУ и не заменяет системные файлы.
- Это обычное приложение и оно не должно намеренно изменять системные процессы или память ядра. Если происходит ошибка ядра, убедитесь, что вы используете недавний метод взлома и загрузчик ELF, или вернитесь к стабильному методу, который вы обычно используете.
- Если вы используете P2JB и этот ELF вызывает панику ядра, избегайте его использования с этой конфигурацией. Стабильность важнее удобства, когда каждая повторная попытка занимает много времени.
- На этапе подготовки может вычисляться размер папки и проверяться доступное пространство. Это может быть медленно, когда папка содержит много файлов, но помогает предотвратить запуск операции копирования, перемещения, загрузки или скачивания, которая не может быть безопасно завершена.
